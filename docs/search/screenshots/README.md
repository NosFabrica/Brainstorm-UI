# Search box screenshots

The images beside this file are what the search grammar looks like in the app — they are
linked from the pull request that introduced it, and are worth keeping only while they are
still true. If the box changes and nobody re-shoots them, delete them rather than leaving a
picture of an older UI in the repo.

They were taken against a throwaway local relay serving a handful of signed fixtures, so the
names and rooms in them ("Joe Martin", "Guitar Gal", the two `general` groups) are invented
and no real person's profile is pictured.
