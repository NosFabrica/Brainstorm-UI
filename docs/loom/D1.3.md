# D1.3 Write the ADR for the first journey

The spec for a decision task on the search roadmap. The decision itself is
[ADR 0008](../adr/0008-first-search-journeys.md).

## Problem

Search is built one journey at a time, and every other search decision is sized by the first one: which lists need
density, which index fields land first, which queries the labelled set leans on. The labelled set
(`docs/search/eval/`) and the data audit (`docs/search/audit-2026-10-22.md`) already assume a first journey, but
nothing records it.

## For whom

The people building search, and every later search decision, which cites this one.

## Done when

One ADR in `docs/adr/` that:

- names the two query classes of the first journeys;
- says which ships first, and why, with the numbers it rests on;
- says how the labelled set is weighted toward them;
- says what the M2 demo must show.

It is proposed first and accepted after the team's R&D call has confirmed or changed it, with any dissent recorded in
it. The decider merges it.

## Out of scope

How a query is interpreted (D4), how people are shown on a result (D2), the index fields themselves (E1), and growing
the labelled set (E6).
