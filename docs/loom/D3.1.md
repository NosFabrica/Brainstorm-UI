# D3.1 Write the rebuild requirement

The spec for a decision task on the search roadmap. The decision itself is
[ADR 0009](../adr/0009-concept-index-rebuilt-from-relays.md).

## Problem

Search will read meaning from a concept index: Vespa's concept documents, projected from the concept graph in
Tapestry's Neo4j and from list headers. The roadmap says signed events on relays are the truth and the index is a
cache, but nothing yet says what that has to mean in practice. If meaning can only be computed on NosFabrica's
machines, nobody can run a second Brainstorm or check the one that exists.

## For whom

Whoever builds the concept document type, the projection job and the linker, and anyone who runs their own Brainstorm.

## Done when

An ADR in `docs/adr/` that:

- states the requirement as a test the engine must pass: what it starts from, what it runs, what passes;
- says what counts as a NosFabrica server, and what "the same index" means;
- says whether today's code and data pass, with the numbers.

The decider merges it.

## Out of scope

The concept document's schema (D3.2), the projection job (D3.3), where the linker runs (D3.4), and per-observer trust
(D6).
